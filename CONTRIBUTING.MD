# Contributing to Discord Bot Dashboard

Thank you for considering contributing to this project! Your contributions are what make this open-source project great.

## How Can You Contribute?

### 1. Reporting Bugs
If you find a bug, please open an issue with:
- A clear and descriptive title.
- Steps to reproduce the issue.
- Expected behavior vs actual behavior.
- Any screenshots or logs, if applicable.

### 2. Suggesting Features
Have an idea for a feature? Open an issue with:
- A detailed description of your feature request.
- Why you believe this feature is useful.
- Any examples or mockups, if applicable.

### 3. Submitting Code
We welcome pull requests! Please follow these steps:
1. Fork the repository and clone your fork locally.
2. Create a new branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
